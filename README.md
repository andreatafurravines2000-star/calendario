# Calendario

Aplicación web para estudiantes: guarda tu horario universitario, agrega tareas y fechas de entrega, y recibe alarmas de recordatorio.

## Funciones
- Horario semanal de clases (curso, día, hora, aula).
- Tareas, trabajos, exámenes y exposiciones con fecha y hora de entrega.
- Alarmas con sonido, vibración y notificación, con aviso configurable (a la hora, 15 min, 1 h, 3 h, 1 día, 2 días).
- Las clases avisan 10 minutos antes.
- Instalable como app, con ícono propio.
- Los datos se guardan en el navegador (localStorage).

## Cómo publicarla
1. Sube todo el contenido de esta carpeta a la raíz del repositorio `calendario`.
2. En GitHub: Settings → Pages → Branch `main` → carpeta `/ (root)` → Save.
3. Abre `https://TU-USUARIO.github.io/calendario/`.

## Instalar como acceso directo
- Android (Chrome): menú ⋮ → “Instalar aplicación”.
- iPhone (Safari): Compartir → “Añadir a pantalla de inicio”.
- Computadora (Chrome/Edge): ícono de instalar en la barra de direcciones.

## Nota sobre las alarmas
Suenan mientras la app esté abierta. Pulsa “Activar sonido y notificaciones” en la pestaña Agregar la primera vez.
